# 📅 Content Calendar Core

Version-agnostic models, abstractions and query logic for **Content Calendar**, the content calendar for the Umbraco backoffice.

> **You don't need to install this package yourself.** Install the edition for your Umbraco version instead; it brings this package in as a dependency:
>
> ```bash
> dotnet add package ContentCalendar.V17
> ```

More information, screenshots and documentation: [github.com/ZAAKS/ContentCalendar](https://github.com/ZAAKS/ContentCalendar)
